Privacy policy

C7RL Change Guard reads, for each pull request on repositories where it is installed: the list of changed file paths and their change type, and the file .c7rl/contract.json on the base branch. It writes one check run per PR head commit.

It does not read file contents other than the contract, does not store repository data, and keeps no database. Requests are processed in memory and discarded. Standard request logs from the hosting provider (Vercel) may be retained for a limited period.

Questions: open an issue at github.com/c7rl-ai/c7rl-github-app.
