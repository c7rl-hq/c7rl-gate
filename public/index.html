C7RL Change Guard

Change control for AI coding agents. C7RL checks every pull request against an approved change contract and fails a required check when files outside the approved scope are touched.

How it works

  1. Add .c7rl/contract.json to your default branch with allowed and protected path globs.
  2. Install the app and make C7RL / scope-check a required status check.
  3. Any agent's PR (Claude Code, Codex, Cursor) is judged deterministically. Out-of-scope files block the merge.
{ "version": 1, "task": "Add password reset", "approvedBy": "eng-lead",
  "allowed": ["src/auth/**", "tests/auth/**"],
  "protected": ["src/payments/**", "infra/**"] }

The contract is read from the PR's base branch, so a PR cannot widen its own scope. .c7rl/** and .github/workflows/** are always protected.
